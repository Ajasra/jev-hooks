# Project North Star: TypeSafe AI Jev

TypeSafe AI Jev is a machine-native semantic hook runtime and helper architecture for autonomous agent harnesses (Google Antigravity and OpenAI Codex).

## Core Mission
Equip coding harnesses with ultra-fast (<120ms), deterministic, and calibrated System One decision primitives that prevent destructive operations, dynamically route specialist skills, verify output citations against ground truth, and prevent context starvation or goal drift.

## Invariant Non-Negotiables
1. **Determinism over Autoregressive Guessing**: Hard invariants (path containment, destructive commands, regex barriers) execute locally in <1ms without network calls.
2. **System One Balance**: Semantic advice remains fast, non-blocking, and advisory while safety remains authoritative.
3. **Zero Lock-In Shared Architecture**: A single shared SQLite audit memory and neutral core (`src/jev/`) powering both Google Antigravity and OpenAI Codex without harness drift.
4. **Context Grounding**: Meaning resides in situated physical context, not bare prompt strings.
